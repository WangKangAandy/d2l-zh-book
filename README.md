# 动手学深度学习 · 中文正文阅读版

从 [D2L 中文原仓库](https://github.com/d2l-ai/d2l-zh)抽取的教材正文，方便直接阅读 Markdown、做学习笔记和逐章编辑。原作者：Aston Zhang、Zachary C. Lipton、Mu Li、Alexander J. Smola；中文内容由原项目及其贡献者维护。本仓库为非官方整理版本。

保留原书通用正文、公式、练习、PyTorch 与通用代码片段、静态配图和参考文献。移除 MXNet、TensorFlow、PaddlePaddle 专用内容，不做框架切换。目录与交叉引用已改为普通 Markdown 链接；没有网站前端、Sphinx 构建、CI 或 `d2l` 运行库，也没有重复的 `_origin.md`。详细来源与改动见 [来源说明](SOURCE.md)，许可原文见 [LICENSE](LICENSE)。

这是**正文提取版，尚未升级 PyTorch 或修订教材知识**。代码片段仍依赖原书运行环境和 `d2l` 包，不能把本仓库当作独立可运行的训练项目。原站执行代码生成的图表输出没有重新运行生成；各篇底部附原版网页链接。

## 如何编辑

直接修改对应 `chapter_*/*.md`。图片放在 `img/`，沿用相对路径；修改标题时保留已有 `<a id="...">`，以免跨章节链接失效。Python 示例仅保留原文标记为 PyTorch 或通用的代码块；原书未提供 PyTorch 实现的章节注明了这一点。

建议每章单独提交。升级环境、修订原理、补充现代模型时，在对应章节说明修改依据和验证范围。
